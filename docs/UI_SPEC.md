# 理包参谋 Overlay UI 规范 v0.1

设计总纲：**框的亮度 = 物品配得上的惊讶程度。**
亮框是稀缺资源——全屏都亮等于全屏都不亮（狼来了效应）。

## 主场景：开盒预判（本产品的心脏）

已开物品的价格标注是**查询工具**，未开容器的预判才是**决策工具**——
玩家站着搜索的每一秒都是被杀窗口，预判的价值 = 省下的 2 秒 + 规避的暴露风险。

**硬指标：开盒后 0.5 秒内出结论**（容器打开 → 格子形状可见 ≈0.3s，
纯查表推理零计算，预算充足）。

### 三信号时序（全部早于搜索完成）

```
t=0      容器品类已知（机箱→电子/医疗堆→医疗/大保险→工艺藏品）→ 顶条显示品类
t≈0.3s   格子形状可见（3x3）→ 形状查锁定组合/诈骗表 → 追加候选物品+估价
t≈1-2s   进度条时长确认品质（~2s→金/红）→ 锁定结论 + 亮框决策
```

### 结论只有三种，没有第四种

| 结论 | 条件 | 顶条表现 |
| --- | --- | --- |
| **★ 锁定高价值** | 容器×形状命中锁定组合 | 亮金预览 + 物品名 + 估价（"主战坦克模型 ~225万"） |
| **⚠ 诈骗预警** | 命中诈骗场景表 | 黄条"仪式匕首，中断搜索"（救你 2 秒） |
| **· 普通/低值** | 无锁定无诈骗 | 灰字一行，不打扰 |

已开物品的标价/亮框规则降为次要场景（见下），服务收尾阶段的取舍。

### 换包模式（预判触发的高级动作）

预判 ★ 高价值时，弹出的不只是"有什么"，还有"**该扔什么**"——
利用容器转圈的 1-2 秒完成换包：垃圾进容器 → 好物进背包。

**铁律：背包估值清单常驻后台维护，预判触发时零计算零延迟。**
（从预判到出货只有 1-2 秒，现算就晚了。）

触发时右缘弹出"腾格榜"（按 哈夫币/格 从低到高）：
- 每件：名称 / 总价 / 格数 / 单位格价值 / 在背包中的位置编号
- 同时背包网格上把这几件打上 **OUT 标记**（红斜角，仅换包模式可见）
- 用户手动拖进容器（系统只指路和标记，永不动手）
- 好物入包后榜单自动消失

数据缺口：普通物品格数表未全（当前仅大红级有形状数据），
v0.1 按总价排序，格数表补齐后升级为 哈夫币/格 排序。

## 次要场景：已开物品分级（每格）

| 级别 | 判定 | 表现 |
| --- | --- | --- |
| 大红/锁定组合 | ≥100万 或 占卜师锁定 | **亮金框**（唯一允许发光的）+ 价格 |
| 高值 | ≥10万 | 细白框 + 价格 |
| 普通 | ≥否决线 | 无框，仅角落价格小字 |
| 垃圾 | 否决规则命中 | **不显示**（灰都不灰，当不存在） |

- 数字每格最多两个：总价 + 哈夫币/格。不要文字标签。
- 大红出现时伴随一次性音效 + 顶部小条（"主战坦克模型 225万"），2 秒自动消失。
- 禁止：闪烁、呼吸灯、全屏色块——视觉噪音比信息更贵。

## 布局

- 一切锚定游戏窗口，**永不遮挡准星与屏幕中心 40%**。
- 容器预测条：屏幕顶部中央，细条一行："大保险 3x3 两圈 → 主战坦克 ~225万"，读完即焚。
- 全局角件（右下角，一小块）：背包总估价 / 格子占用率 / 当前最高价值单件。

## 技术形态（明日实现）

- 透明点击穿透窗（PySide6/tkinter：`WS_EX_TRANSPARENT|LAYERED|TOOLWINDOW`），
  无边框置顶，鼠标事件穿透到游戏。
- 截屏用 dxcam（GPU 侧抓帧，~1ms 级）。
- 网格标定一次写入 config（背包格坐标系、格子像素尺寸）。
- 增量刷新：帧差分，只重算变化格。
- 性能预算：全屏 60 格识别 <600ms（当前 9.9ms/格，增量后稳态 ≈0）。

## 语音层（贾维斯预留）

大红/威胁事件走 TTS 播报（"左后有人""呼吸机四百万"），
眼睛永远不用离开准星——文字是给人扫的，语音是给人听的。
