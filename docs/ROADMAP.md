## v0.3 语义与全空间（依赖：v0.2 数据管线）

- [ ] 行为声子类：换弹 vs 打药 vs 缠绷带（节奏+频谱双特征）
- [ ] 干员识别：技能声纹 + 技能台词双特征；operators.json 填 CD
- [ ] CD 追踪战术闭环：技能检测 → "敌方威龙位移已交，推进窗口开启"
- [ ] 多人计数：onset 序列步频梳齿 + 方向通道分离（2-3 人可靠）
- [ ] 止步检测：脚步节奏突变 → "他停了"（战术价值最高的事件之一）

## 远期矿层（方向感，不排期）
- 枪皮声纹 → 特定玩家跨局识别（声音版人脸识别）
- 小队融合感知网（三人交叉确认 → 全向覆盖）
- 商用窗口：平台白名单信号 → 全量产品化（见 HARVEST.md 分层决策）
- **局内物资识别**（用户 03:52 定调）：难点是机器识别速度；价值量化=哈夫币/格
  （"有些 4x4 紫色还不如 1x1 蓝色值钱"）；配件拆装链（一把枪背着一堆配件走）
- **小兵状态推断**：固定人机位置 + 行为状态（是否被清过/敌人是否还在）→
  "这里来过敌人没"的音频/态势答案
- **假账局识别**：三角洲特色——系统填充局检测（从声音密度/真实玩家信号推断），
  影响搜刮策略的风险评估输入
